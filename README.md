# WarehousePro - Inventory & Order Management System

WarehousePro is an interactive web-based warehouse management terminal designed for real-time inventory tracking, receiving, order picking, and stock movement.

## Features

- **Terminal Authentication**: Modern sign-in interface with demo role quick-access (Warehouse Staff, Inventory Lead, Operations Supervisor).
- **Interactive Dashboard**: KPI summaries (Total SKUs, Low Stock Alerts, Pending Orders, Inbound Shipments) and live activity feed.
- **Inventory Tracking**: Searchable SKU catalog with stock levels, bin locations, and categories.
- **Receiving & Inbound**: Log arriving purchase orders, verify quantities, and assign storage bins.
- **Orders & Picking**: Pick list generation and status dispatch workflow.
- **Stock Movement**: Real-time bin-to-bin transfers and adjustment logging.
- **Reports & Analytics**: Visual breakdown of inventory valuation, movement velocity, and discrepancies.

## Tech Stack

- **HTML5**: Semantic UI layout and accessible modal dialogs
- **CSS3**: Responsive flexbox/grid layout, custom design tokens, and modern typography
- **Vanilla JavaScript**: State-driven navigation, modal management, and dynamic rendering

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/gabreliii/HCI-proj-draft.git
   ```
2. Open `index.html` in any modern web browser or run with a local server (e.g. Live Server).
3. Select a demo role on the login screen or enter credentials to enter the terminal.
